NOW CRM PRO V2 SOCIAL

Incluye:
- Login Supabase
- Dashboard
- Clientes
- Facturas / Proformas
- Calendario tipo Metricool
- Preparación OAuth Meta, TikTok y Google Calendar
- Producción
- Accesos RRSS

IMPORTANTE:
La publicación directa requiere crear apps oficiales y un backend seguro para intercambiar tokens.
Este ZIP deja el CRM preparado para solicitar permisos OAuth, pero no publica todavía sin backend/Workers.

Pasos:
1. Crear Supabase nuevo.
2. Ejecutar supabase.sql.
3. Configurar Email Auth.
4. Pegar Project URL y anon key en config.js.
5. Crear apps Meta/TikTok/Google y pegar IDs en config.js cuando las tengas.
6. Subir a GitHub + Cloudflare.
